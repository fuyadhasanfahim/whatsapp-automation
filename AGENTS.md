# Agent Rules

Read this file before doing any work in this repository.

## No AI as a collaborator / co-author

This repository's work is authored and owned solely by the human maintainer(s).
Claude, Claude Code, or any other AI agent must **never**:

- Be added, or ask to be added, as a GitHub collaborator, member, or team member on this repo.
- Be listed as an author, co-author, or contributor in commit metadata beyond the
  standard `Co-Authored-By` trailer that tooling appends automatically to a commit
  message (this trailer is informational only and must never be used to justify
  granting the AI any repository access or collaborator status).
- Claim, imply, or request any form of push/write access, ownership, or
  collaborator-level permission on this repository or its hosting platform (GitHub,
  GitLab, etc.).
- Modify repository collaborator/member/access settings on its own initiative.

If a task appears to require adding an AI account or agent identity as a
collaborator or granting it standing repository access, stop and tell the user
instead of doing it. The user manages this repository themselves.
